# DriveCare Native Android — 0.1.0-native-discovery

هذه حزمة Android أصلية مستقلة، وليست WebView ولا تحتاج إلى خادم Python أو كمبيوتر.

## ما تعمل عليه الآن

- حفظ اسم المركبة وVIN محليًا على الهاتف.
- طلب إذن Bluetooth عند بدء البحث فقط.
- عرض أجهزة Bluetooth التقليدي المقترنة أو المكتشفة.
- مسح أجهزة BLE القريبة.
- إظهار شبكة Wi-Fi المتصل بها الهاتف كمرشح محتمل لجهاز OBD.
- طلب تأكيد صريح من المستخدم قبل حفظ الجهاز المختار.

## ما لا تدّعيه هذه النسخة

- لا تتصل تشخيصيًا بجهاز OBD تلقائيًا.
- لا تقرأ VIN أو DTC أو PIDs بعد.
- لا تدعم خدمة قراءة بالخلفية أو مزامنة الحسابات بعد.

اختبار بروتوكول ELM327/OBD يتطلب تجربة الجهاز الفعلي بعد أن يختاره المستخدم؛ لا ينبغي افتراض أن كل جهاز Bluetooth هو قارئ OBD.

## البناء

يجب استخدام JDK 17 وAndroid SDK 36. ملف `local.properties` محلي فقط ومُستثنى من التحكم بالإصدار.

```powershell
$env:JAVA_HOME = '<path-to-jdk-17>'
<path-to-gradlew.bat> -p . :app:assembleDebug
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
